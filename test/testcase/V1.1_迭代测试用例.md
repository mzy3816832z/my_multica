## 一、PICT 组合测试

### 1.1 约定

- 用例编号 `PICT-*`，其下每条生成用例以 `PICT-1-01` 形式编号。
- 预期结果遵循每组的「预期结果判定规则」，对生成用例给出可直接断言的判定。
- 成对（2-way）覆盖：任意两个参数的取值组合至少出现一次。

### 1.2 PICT-1 房源列表组合筛选

参数与取值（等价类 + 边界/异常值）：

| 参数 | 取值 | 说明 |
|---|---|---|
| sort | latest / price_asc / price_desc | 排序方式 |
| keyword | none / name_match / addr_match / desc_match / no_match | 关键词匹配范围 |
| district | none / valid / invalid | 行政区筛选 |
| layout_type | none / studio / one_bedroom / invalid_code | 户型筛选 |
| lease_term | none / 1_year / 6_months / invalid_code | 租期筛选 |
| price | none / in_range / no_overlap | 价格区间 |
| metro | none / hit_station / miss_station | 地铁站点（≤1.5km） |

PICT 模型：

```
# 房源列表组合筛选（接口 GET /api/v1/apartments）
sort: latest, price_asc, price_desc
keyword: none, name_match, addr_match, desc_match, no_match
district: none, valid, invalid
layout_type: none, studio, one_bedroom, invalid_code
lease_term: none, 1_year, 6_months, invalid_code
price: none, in_range, no_overlap
metro: none, hit_station, miss_station
```

**预期结果判定规则**（每条生成用例据此断言）：

| 参数取值 | 断言 |
|---|---|
| sort=latest | 返回按 `updated_at` 倒序 |
| sort=price_asc | 按 `min_monthly_rent` 升序，`null` 排最后 |
| sort=price_desc | 按 `min_monthly_rent` 降序，`null` 排最后 |
| keyword=name_match | 返回的房源 `name` 含关键词；同关键词时 name 精确>name 包含>地址>描述 的排序权重 |
| keyword=addr_match | 返回的房源 `detail_address` 含关键词 |
| keyword=desc_match | 返回的房源 `description` 含关键词 |
| keyword=no_match | `data.items` 为空数组，`total=0` |
| district=valid | 返回房源 `district_id` = 筛选值 |
| district=invalid | `data.items` 为空数组（无匹配行政区） |
| layout_type=invalid_code | `data.items` 为空数组 |
| lease_term=invalid_code | `data.items` 为空数组 |
| price=no_overlap | `data.items` 为空数组 |
| metro=hit_station | 返回房源距所选站点 ≤1.5km |
| metro=miss_station | `data.items` 为空数组（含该站点 1.5km 内无房源） |

### 1.3 PICT-2 房源编辑变更审核触发

参数与取值：

| 参数 | 取值 | 说明 |
|---|---|---|
| field_group | apt_A / room_A / apt_exempt / room_exempt / mixed_A_exempt | 本次编辑涉及的字段类别 |
| current_status | published / offline | 房源当前状态 |
| has_pending_change | yes / no | 是否已存在 pending 变更审核单 |

PICT 模型：

```
# 房源编辑变更审核触发（PUT /api/v1/merchant/apartments/{id}）
field_group: apt_A, room_A, apt_exempt, room_exempt, mixed_A_exempt
current_status: published, offline
has_pending_change: yes, no
```

生成用例（10 条，覆盖全部 24 个参数对）：

| 用例编号 | field_group | current_status | has_pending_change | 预期结果 |
|---|---|---|---|---|
| PICT-2-01 | apt_A | published | yes | `code=409001`，message「已有变更待审核，请等待审核完成」，不创建新审核单 |
| PICT-2-02 | apt_A | offline | no | 生成 change_review 审核单，`updated=false`，status 保持 `offline`（不置 change_reviewing） |
| PICT-2-03 | room_A | published | no | 生成 change_review 审核单，`updated=false`，status=`change_reviewing` |
| PICT-2-04 | room_A | offline | yes | `code=409001`，不创建新审核单 |
| PICT-2-05 | apt_exempt | published | yes | 直接更新（`updated=true`，`audit_id=null`），status 保持 `published`，pending 审核单不受影响 |
| PICT-2-06 | apt_exempt | offline | no | 直接更新（`updated=true`，`audit_id=null`），status 保持 `offline` |
| PICT-2-07 | room_exempt | published | yes | 直接全量替换房型（`updated=true`），status 保持 `published` |
| PICT-2-08 | room_exempt | offline | no | 直接全量替换房型（`updated=true`），status 保持 `offline` |
| PICT-2-09 | mixed_A_exempt | published | yes | `code=409001`，不创建新审核单，免审字段也不生效 |
| PICT-2-10 | mixed_A_exempt | offline | no | 生成 change_review 审核单（A 类变更触发），status 保持 `offline` |

> 说明：`apt_A`（公寓 A 类：name/district_id/street_id/detail_address/longitude/latitude/cover_image）、`room_A`（房型 A 类：images/layout_type/window_type/area）、`apt_exempt`（公寓免审：description/contact_phone/费用字段）、`room_exempt`（房型免审：floor/facilities/available_date/sort/rental_plans）。

### 1.4 状态机转移矩阵（非 PICT，作为转移表）

| 当前状态 | 操作 | 目标状态 | 结果 |

| pending_first_review | 管理员通过 | published | 首次审核通过 |

| published | 编辑 A 类字段 | change_reviewing | 影子发布，创建 change_review |
| published | 编辑免审字段 | published | 直接更新 |
| published | 下架 | offline | 仅 published 可下架 |
| published | 管理员变更通过 | published | 新版本生效 |
| published | 管理员变更驳回 | published | 旧版继续展示 |
| change_reviewing | 商家撤回 | published | 软删除 change_review 审核单 |
| change_reviewing | 管理员通过 | published | 新版本生效 |

| offline | 编辑 A 类字段 | offline | 创建 change_review 但保持 offline |
